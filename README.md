# DevOps Lab Experiments

## Experiment 1: Advantages and Business Impact of DevOps

Evaluating the impact of DevOps on deployment frequency,
lead time, failure rate, recovery time, operational
efficiency and customer satisfaction.

## Experiment 2: Merge Conflicts and Resolution

Demonstrating Git branches, merge conflicts,
conflict identification and resolution.

## Experiment 3: Automated Testing and Continuous Feedback

Implementing Python unit testing using pytest
and continuous integration using GitHub Actions.

## Technologies Used

- Python
- Git
- GitHub
- VS Code
- pytest
- GitHub Actions

## Project Purpose

To understand practical DevOps concepts,
version control, automated testing and CI pipelines.
